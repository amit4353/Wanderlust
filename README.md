# WanderLust

🏡 An Airbnb-inspired full-stack accommodation booking platform built with Node.js, Express.js, MongoDB, and EJS.

## Features

- User Authentication & Authorization
- CRUD Operations for Listings
- Image Uploads with Cloudinary
- Session Management
- Server-Side Validation
- Error Handling
- Responsive UI

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- EJS
- Cloudinary
- Multer
- Joi

## Installation

```bash
npm install
npm start
```
